# 001 - Domain-Agnostic Stateful Architecture

Aldan is fundamentally a **domain-agnostic stateful cognitive platform**, not merely a specialized coding agent. While software engineering is one high-value application, the platform core treats domain specializations as emergent properties of user interaction rather than hardcoded system invariants.

---

## Architectural Principle: Domain Neutrality

1. **The Neutral Core**:
   - The foundational reasoning layer does not hardcode coding assumptions (`techStack`, `pair programming`, `syntax trees`).
   - The core persona is that of a **rigorous, stateful cognitive partner** that listens, infers implicit intent, maintains cross-session memory, and adapts to the user's specific context.

2. **Emergent Domains**:
   - An attorney using Aldan should experience an agent that adapts to statutory interpretation, case law citations, and litigation strategies.
   - A biomedical researcher should experience an agent that adopts molecular biology terminology, experimental rigor, and paper synthesis standards.
   - A software engineer should experience an agent that writes functional TypeScript, manages git worktrees, and debugs systems.

3. **Separation of Cognitive Capabilities**:
   - **Core Engine**: Context compilation, memory reconciliation, decay modeling, and continuous user adaptation.
   - **Domain Facets**: Dynamic metadata and semantic memories extracted from actual conversation topics.
